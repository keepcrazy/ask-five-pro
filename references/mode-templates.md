# 六种会议模式展开模板

本文件提供展开结构和示例，不定义新的运行规则。规范性流程以根 `SKILL.md` 为准，所有模式仍需使用七类外层输出。

## 1. 共识

模式结果可以包含：

- 独立判断的共同部分
- 共识成立条件
- 主要分歧
- 阻断性意见
- 需要验证的事实

不得把多数意见写成全体共识。

## 2. 对抗

在 2–3 轮内完成有效交锋：

1. 开篇：各方给出初始立场、关键前提和最强论据。
2. 交锋：每方引用对方上一轮具体论点，攻击其最弱前提并回应反驳。
3. 可选深化：仅在仍有关键问题未交锋时增加第三轮。
4. 结辩：各方先认可对方至少一点，再给出修正后的最终立场。
5. 组织者 verdict：比较证据与推理强弱，给出胜因、平衡点和条件化选项。

两轮已经完成有效交锋时可以结辩，不能把三轮示例误写成固定要求。

## 3. 红队

模式结果聚焦：

- 漏洞
- 风险等级
- 最可能的失败路径
- 致命假设
- 最小验证方式
- 停止条件

“只输出漏洞、风险、失败路径”只约束本模式结果段；边界声明、会议信息、专家发言、综合、行动选项和结尾提醒仍然存在。

## 4. 陪审团

模式结果包含：

- 每位专家的投票与理由
- 投票分布
- 多数意见
- 少数意见
- 关键假设
- 什么新证据会改变投票

阻断性安全、合规或不可逆风险不能被多数票覆盖。

## 5. 预审

从“这个决策已经失败”倒推：

1. 失败结果是什么；
2. 哪条路径导致失败；
3. 根因和关键假设是什么；
4. 哪些早期预警会出现；
5. 如何预防或降低损失；
6. 哪些信息仍需验证。

“只输出失败路径”只约束本模式结果段，不取消七类外层输出。

## 6. 淬火

### 初议

初议专家独立给出判断，并形成初步综合。

### 确认

- 普通议题：展示初议结论，等待用户确认是否进入挑刺。
- 高利害议题：自动进入挑刺，并明示已经进入淬火审查。

### 挑刺

挑刺专家必须与初议专家不同。逐条检查：

- 最弱前提
- 致命反例
- 不可逆风险
- 缺失信息
- 需要补充的验证

### 最终综合

输出经挑战后的结论、置信度、剩余风险和结论成立条件。

## 系统组织者边界

系统组织者可以整理证据、识别多数意见、比较推理强弱，但不能：

- 占用专家名额；
- 产生独立专家立场；
- 替用户完成价值选择；
- 把条件化选项写成无条件命令。
