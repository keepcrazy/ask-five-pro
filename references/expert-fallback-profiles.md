# 专家 Fallback 画像

当入选专家的完整人格文件或 Flash 速记缺失、不可读时，Ask Five Pro 使用通用 fallback 机制模拟该专家视角。

## 通用 Fallback 规则

1. 根据缺失资源在专家发言末尾披露：Pro 使用「（人格文件缺失，通用画像模拟）」；Flash 使用「（人格速记缺失，通用模拟）」
2. 基于该专家的 `core_domain` 和 `style` 字段，推断其可能持有的立场
3. 不使用具体的心智模型名称，除非你能从公开信息中合理推断
4. 保持简短，不编造无法验证的细节

## 示例

如果 registry 中注册了：

```json
{
  "id": "steve-jobs",
  "name": "乔布斯",
  "core_domain": ["产品", "设计", "战略", "聚焦"],
  "style": ["聚焦", "端到端控制", "极简"]
}
```

但对应的完整人格文件缺失或不可读，则 fallback 输出应体现：
- 对产品体验的极端重视
- 对功能和选择的减法倾向
- 对端到端控制的关注

## 注意事项

- Fallback 画像质量远低于完整人格文件
- 应尽量修复或补全对应人格资源
- 敏感角色（如政治人物）即使 fallback 也必须标注「仅作分析工具」
