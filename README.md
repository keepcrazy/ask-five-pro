# Ask Five Pro

Ask Five Pro 是一个开箱即用的专家议会 Skill。它从 40 位跨领域专家人格中匹配合适成员，通过结构化会议提供多元视角、暴露分歧和风险，并输出条件化行动选项。

它是思维与决策辅助工具，不替用户作最终决定，也不替代医生、律师、投资顾问或危机干预人员。

## 核心能力

- 内置 40 位专家、5 个专家包，无需额外安装专家库。
- 支持共识、对抗、红队、陪审团、预审、淬火六种会议模式。
- 根据议题类别自动匹配 3–5 位专家；用户明确点名时可扩容。
- 支持 Flash 速记人格与 Pro 完整人格两种深度。
- 统一采用七类输出结构：边界声明（如有）、会议信息、专家独立发言、模式结果、四级综合、条件化行动选项和结尾提醒。

## 快速使用

```text
叫专家团开会：我们要不要重构当前产品？
```

```text
让专家团做一次红队审查：这个商业方案最可能怎么失败？
```

```text
用 flash 模式，让乔布斯、费曼和芒格讨论这个产品方向。
```

未指定会议模式时默认使用共识模式；未指定人格深度时，人类对话默认使用 Pro。

## 六种会议模式

| 模式 | 适用场景 | 核心结果 |
|---|---|---|
| 共识 | 汇总多方判断 | 共识、条件与分歧 |
| 对抗 | 比较相反立场 | 交锋、结辩与裁判结果 |
| 红队 | 主动寻找薄弱点 | 漏洞、风险和失败路径 |
| 陪审团 | 二选一或需要投票 | 投票分布、多数与少数意见 |
| 预审 | 决策执行前预想失败 | 根因、预警和预防措施 |
| 淬火 | 对初步结论继续施压 | 挑刺后的结论、置信度与剩余风险 |

## Flash 与 Pro

| 深度 | 加载内容 | 适用场景 |
|---|---|---|
| Flash | 仅加载入选专家的人格速记 | 快速咨询、低成本调用 |
| Pro | 加载入选专家的完整人格文件 | 复杂问题、重要或不可逆决策 |

涉及金额、合同、对外承诺或不可逆决策时，强制使用 Pro。

## 执行链路

```text
识别 Flash/Pro 与会议模式
→ 确认议题
→ 边界检查
→ 推断类别和约束
→ 匹配并按需确认专家名单
→ 只加载入选专家人格
→ 组织会议
→ 四级综合
→ 七类输出与自检
```

完整规则以 [`SKILL.md`](SKILL.md) 为准。

## 目录结构

```text
ask-five-pro/
├── SKILL.md                         # 权威工作流与执行规则
├── brain-crew/
│   ├── expert-registry.json         # 40 位专家的唯一索引
│   ├── flash-profiles/              # Flash 人格速记
│   ├── packs/                       # Pro 完整人格与其必要资源
│   └── scripts/matching_core.py     # 专家匹配核心逻辑
├── scripts/
│   ├── boundary-guard.py            # 边界分类
│   └── match-experts.py             # 专家匹配入口
└── references/                      # 模式、输出和 fallback 参考材料
```

名单确认、人格加载、会议执行和综合由根 Skill 指导宿主模型完成；脚本只负责边界分类与专家匹配。

## 专家来源

所有真实人物人格都是思维框架模拟，不代表本人当前观点。遇到资料未覆盖或超出人物时代的问题，只能基于已加载材料作有限推演。
