# Extension workspace

`extension/` 是未来新增专家的暂存说明目录，不是正式 pack，也不计入当前 pack 数。

当前正式分布固定为：

- core 6
- brand 10
- tech 7
- enterprise 12
- meta 5

合计 40 位专家、5 个 pack。

将新专家加入正式产品前，需要同步：

1. `brain-crew/expert-registry.json`
2. `brain-crew/flash-profiles.md`
3. 专家源版本记录
4. 当前资产与匹配测试

现有 40 位专家的完整性修复只允许从固定源版本原样恢复，不通过质量评分决定迁移。
